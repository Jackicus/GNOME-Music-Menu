Apple Music UI Component Architecture

Apple Music's web frontend is architected as a modular component hierarchy. Below is a complete specification of the 8 core building blocks, including their API data contracts, React/TypeScript component implementations, and guidelines for GNOME desktop integration.

AppSidebar (Navigation Rail) Layout Container

Left docked navigation tree providing instant switching between Storefront, Personal Library, and User Playlists.

Library
Songs
Albums
Data Contract & Props
interface NavItem { id: string; label: string; icon: React.ComponentType; path: string; badgeCount?: number; } interface AppSidebarProps { currentRoute: string; userPlaylists: MusicKit.LibraryPlaylist[]; onNavigate: (route: string) => void; onSearch: (query: string) => void; }
GNOME / Desktop Adaptation
  • Map to Adw.NavigationSplitView with sidebar on the left and content in the detail page.
  • Use Gtk.ListBox with .navigation-sidebar CSS class for native GNOME 47 HIG feel.
  • Support collapse to compact icon rail or bottom sheet on small screen sizes.

PlayerBar (Playback Deck & LCD Scrubber) Persistent Audio Control

Persistent translucent dock containing current track lockup, transport controls, LCD scrub bar, and panel triggers.

React Implementation Code
export const PlayerBar: React.FC<PlayerBarProps> = ({ nowPlaying, isPlaying, playbackTime, duration, onTogglePlay, onSeek, onToggleLyrics, }) => { return ( <footer className="player-bar backdrop-blur"> <NowPlayingLockup item={nowPlaying} /> <TransportControls isPlaying={isPlaying} onToggle={onTogglePlay} /> <Scrubber current={playbackTime} total={duration} onSeek={onSeek} /> <UtilityControls onLyrics={onToggleLyrics} /> </footer> ); };
Desktop System Integration
  • Integrate directly with Linux MPRIS2 D-Bus interface (org.mpris.MediaPlayer2) for hardware keyboard media keys and GNOME Quick Settings widget.
  • Smooth audio volume fading via PipeWire/PulseAudio API.
  • Support system tray icon with mini playback controls.

PowerSwoosh (Hero Editorial Carousel) Hero Display

Full-width dynamic carousel with high-resolution artwork, gradient scrim, headline typography, and action buttons.

Data Structure
interface HeroPromoItem { id: string; badgeText: string; headline: string; editorialDescription: string; artworkUrl: string; primaryAction: { label: string; playParams: MusicKit.PlayParameters; }; }
GNOME / Desktop Adaptation
  • Implement with Adw.Carousel and Adw.CarouselIndicatorDots for smooth gesture swiping.
  • Generate dominant background color using Gdk.Pixbuf or Web Canvas palette extraction.

ContentShelf & ProductLockup Collection & Media Cards

Horizontal scrolling carousel or responsive grid displaying album, playlist, or station cards with hover-to-play interactions.

ProductLockup Variations
  • Square Lockup: 1:1 ratio for Albums and Playlists (border-radius: 10px).
  • Circular Lockup: 1:1 circular mask for Artists.
  • Category Brick: 16:9 gradient cards for Genres (Pop, Rock, Anime, Classical).
  • Radio Lockup: Live broadcast badge with animated frequency wave.
React Props
interface ProductLockupProps { id: string; type: 'album' | 'playlist' | 'artist' | 'station'; title: string; subtitle: string; artworkUrl: string; isExplicit?: boolean; onPlay: (id: string) => void; onClick: (id: string) => void; }

Tracklist & SongRow Virtual Table

High-performance table displaying track index, artwork thumbnail, title, artist, lossless badges, favorite star, duration, and context menu.

Anatomy & Hover States
  • Hover on row swaps track index number for Play/Pause triangle button.
  • When track is active, renders animated four-bar equalizer soundwave.
  • Badges for Explicit (E) and Lossless / Apple Digital Master audio.
  • Inline Favorite Star button triggers cloud library mutation.
Performance Strategy
  • Use react-window or @tanstack/react-virtual for playlists with 1,000+ tracks.
  • In GTK/GNOME, use Gtk.ListView backed by Gio.ListStore with factory recycled row widgets.

Time-Synced Lyrics Pane Interactive Karaoke

Live scrolling lyrics aligned to audio timestamps, featuring line-by-line glow effects and tap-to-scrub functionality.

Sync Engine
interface SyllableSync { text: string; startTime: number; endTime: number; } interface LyricLine { id: string; startTime: number; endTime: number; text: string; syllables?: SyllableSync[]; }
Visual Enhancements
  • Blurred mesh gradient background generated from current album art.
  • Autoscroll active line into center of viewport with smooth spring easing.
  • Clicking on any line instantly jumps playback time (musicKit.seekToTime()).
